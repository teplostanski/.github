# Contributing

Thanks for your interest in contributing!

## Code of Conduct

Please follow our [Code of Conduct](./CODE_OF_CONDUCT.md).

## Issues

- Search existing issues first to avoid duplicates.
- Bug reports require a [minimal reproduction](https://stackoverflow.com/help/minimal-reproducible-example). Issues without one may be closed.
- For why reproductions matter, see [Anthony Fu's guide](https://antfu.me/posts/why-reproductions-are-required).
- Typo / grammar fixes: prefer opening a pull request directly.

## Pull requests

- Check that there isn't already a PR that solves the same problem.
- Describe **what** the PR changes and link related issues (e.g. `fixes #123`).
- Include tests when practical.
- Fill out the PR template completely, including the **AI usage** section. Undisclosed AI-assisted PRs will not be reviewed and will be closed.

## Support

If this project has been helpful, consider supporting via [donate.teplostanski.me](https://donate.teplostanski.me).
